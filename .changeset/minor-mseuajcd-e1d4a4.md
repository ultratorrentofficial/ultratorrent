Torrent Activity Scheduler, phase 3: Observe Only. The scheduler can now plan continuously and explain itself, and it still cannot touch a torrent. Every engine defaults to native mode, which is exactly today's behaviour, so an upgrade enrols nobody: an engine with no configuration row and an engine explicitly set to native mean the same thing, and both mean leave it alone. Observe Only is a property of the wiring rather than a rule to remember. The sweep service holds no provider reference at all — the engine registry is injected only to enumerate ids, and its other collaborator computes a plan from database rows — so there is no code path from the timer to pauseTorrent, and a test asserts the constructor mentions no lifecycle call. Engines in native mode are skipped before any query runs, so an installation that never opted in does no scheduler work whatsoever. The preview reads the TorrentSnapshot rows TorrentSyncService already maintains rather than polling engines a second time, which avoids both extra load and a preview that disagrees with every other screen. It runs the same pure planner enforcement will use, so what an operator validates in Observe Only is what enforcement would do. Parked torrents are read from the existing ParkedTorrent table and classified as owned by TorrentParkingService, so the two never contend for the same torrent. Capabilities are read off the shipped providers rather than assumed: rTorrent's force-start is graded approximated because its own code says it has no force flag and uses priority 3, its queued-state reporting is unsupported because its normalizer has no QUEUED mapping at all, and seed-duration reporting is unsupported on BOTH engines because nothing in this repository records it — so time-based seed targets are honestly unenforceable today rather than silently treated as zero. Managed mode is refused with an explanation: there is no reconciliation layer, and a mode that implies enforcement while enforcing nothing would lead an operator to stop watching their queue. Three new tables, one migration that alters nothing existing, two RBAC permissions rather than the nine the design sketched, because a permission guarding nothing teaches operators that grants are decorative. 50 unit tests.
