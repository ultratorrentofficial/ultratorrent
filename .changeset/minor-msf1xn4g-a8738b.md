Torrent Activity Scheduler: recurring schedule windows, completing phase 7. Windows override the resolved policy by time of day, and are stored as local wall-clock minutes plus an IANA zone rather than UTC instants — an operator who says 'throttle overnight' means THEIR night, and their night moves twice a year. Evaluation asks the clock and holds no state, which is what makes the awkward cases harmless rather than special: a restart loses nothing because there is nothing to lose, and a clock moved backwards simply produces the answer for the earlier time instead of corrupting a window that had already fired. Nothing fires; a window either covers this instant or it does not. Daylight saving comes out right for free by asking Intl for the local time in the window's own zone, including both pathological days — a window inside the hour the clocks skip never occurs, and one inside the hour that repeats occurs twice, which are the correct readings of what the operator wrote rather than errors. A window whose end is before its start crosses midnight, and the day-of-week test then applies to the day it BEGAN on, so 'Friday 22:00 to 02:00' runs into Saturday morning without Saturday being ticked. Overlaps resolve by priority and then by id, so a tie always resolves the same way rather than flapping between sweeps; the highest-priority window that sets a field wins it, letting a broad overnight window set a rate while a narrow maintenance window on top sets only concurrency. An unrecognised timezone or a zero-length window makes that window inert rather than taking the sweep down or being guessed at. Wiring the feature caught a real discrepancy between intent and behaviour: 'do not start new downloads' had been folded into a concurrency ceiling of zero, which would have put every download already in flight over the limit and PAUSED it. Declining to begin more work and stopping work already underway are different promises, so it is now carried as its own flag that gates only the resume path, with tests pinning that a download in flight keeps running and that seeding is unaffected. 23 unit tests.
