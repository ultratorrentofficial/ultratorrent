The Duplicate Center gains a Movie Identity tab, which repairs the thing its other tabs group on. A contaminated external ID makes the engine present DIFFERENT films as one duplicate, so acting on the recommendation deletes a real movie and reports reclaimed space — the detection is faithful, its input is a lie. The tab re-derives each identity from the folder name (which the renamer never rewrote), shows the stored ID beside the proposed one and the full path so the mismatched filename is visible, and leads with the rows a human might disagree with. It never runs on mount, because a preview is one provider call per affected folder; and applying sends no plan, so a client cannot direct which ID lands on which item.
