The two features called 'cleanup' now say which is which. Media Settings had 'Cleanup rules' (erases junk FILES left by a download — YTS*.txt, RARBG.txt, unwanted-language subtitles) and the Cleanup Center reclaims space by removing MEDIA. Same word, unrelated jobs, and Library Browser only offers the second — so an operator looking for the basic junk tidy-up finds a policy engine that deletes films. The junk one is now 'Junk file removal' and says it never deletes video, and the Cleanup Center says it removes media and points at the other for junk. Naming only; no behaviour changes.
