The Cleanup Center is now Media Purge. Its name never said what it does: it deletes your actual movies and episodes to reclaim space, while a separate feature called 'Cleanup rules' erases junk files and never touches video. Two features, one word, opposite stakes — and the pages under it inherited the ambiguity (Cleanup Policies, Cleanup Runs, Cleanup Quarantine). Renamed throughout in both locales: Media Purge, Purge Policies, Purge Plans, Purge Runs, Purge Quarantine, Purge Protections, with descriptions that say media rather than files. Display strings only — routes, permission keys and the module key are unchanged, because they are identifiers and renaming them would rewrite stored permission rows for no user benefit.
